# 📊 AD PULSE ANALYTICS
### Global Ads Performance Dashboard | Power BI

## 📌 Project Overview
AD PULSE ANALYTICS is an interactive Global Ads Performance Dashboard built using Microsoft Power BI. The project focuses on analyzing advertising performance and transforming raw data into meaningful business insights.

## 🎯 Project Objectives
- Monitor advertising revenue and spending.
- Analyze advertising performance across platforms.
- Compare ROAS across different industries.
- Understand country-level advertising performance.
- Track monthly advertising trends.

## 📊 Key Features
- **KPI Cards:** Total Revenue, Total Ad Spend, Blended ROAS, Total Conversions.
- **Monthly Trends:** Revenue and Ad Spend analysis.
- **Platform Analysis:** Advertising spend across platforms.
- **Industry Analysis:** ROAS comparison across industries.
- **Geographic Analysis:** Country-level performance.
- **Interactive Filters:** Platform and month selection.
